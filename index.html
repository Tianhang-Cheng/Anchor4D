Key idea: surface neighbors, not spatial neighbors

Two parts can touch in space yet lie far apart on the surface. Our attention measures distance along the surface, so a hand resting on a hip does not drag the hip.

Two measures per dataset. GPT judge: how closely each animation follows the reference video; each bar counts the segments where ours is preferred, similar, or the baseline is preferred. Measured error: 3D error on ARCTIC, PhysTwin and DyCheck, and 2D track error on DAVIS, which has no 3D ground truth.

Ours betterAbout the sameBaseline better% = preference averaged over clips, ties count half

Judge: GPT-6 Astra (high reasoning). It sees synchronized video and anonymous renderings in segments of up to 2 s, with three judgments in each A/B order. A segment counts as a win or loss only when both orders agree. Scores weight segments by length, average equally over clips and count ties as half. The GPT-Astra baseline shares the judge's model family. DyCheck and PhysTwin use the displayed finetuned R-DMesh. PhysTwin covers all 22 clips. The full protocol is in the paper.

Failure case and limitations

DAVIS breakdance. The mesh reconstructed from the first frame fuses the forearm to the head. All methods animate this same mesh, so none of them, ours included, can separate the two parts when the arm moves away later in the clip.

  • Fast motion within a window can reduce reconstruction accuracy.
  • The VAE deforms a fixed reference mesh, so it cannot change topology (no tearing or splitting).
  • Errors can add up over chained windows in long sequences.
  • A single view constrains depth motion and hidden parts only weakly.
  • On real videos, errors in the reconstructed mesh and the completed video carry over to the animation.
